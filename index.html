Cara mendapatkan API Key

02 / PANDUAN
  1. Buka Google AI Studio — API Keys dan login dengan akun Google.
  2. Klik “Create API Key”, pilih project (atau buat baru), lalu salin key yang muncul.
  3. Tempel key di panel sebelah kiri, lalu klik Simpan Key.
  4. Klik Uji Koneksi untuk memastikan key aktif, lalu kembali ke tab Generator.

Jangan bagikan API Key ke siapa pun. Key yang bocor bisa dipakai orang lain dan menghabiskan kuota akun Google kamu.
